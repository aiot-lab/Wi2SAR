# Wi²SAR Project Website

Landing page for the Wi²SAR (Wi-Fi-based Wilderness Search and Rescue) project.

## Overview

This is the official website for Wi²SAR, a drone-based wireless system designed for wilderness search and rescue operations. The project leverages Wi-Fi technology for victim discovery and identification in challenging environments.

## Project Structure

```
wisar_website/
├── index.html              # Main HTML file
├── assets/
│   ├── style.css          # Main stylesheet
│   ├── main.js            # JavaScript functionality
│   ├── images/            # All image assets
│   ├── videos/            # Video assets
└── README.md              # This file
```

## Features

- **Responsive Design**: Optimized for all screen sizes
- **Interactive Animations**: Smooth scroll effects and hover interactions
- **Auto-playing Carousel**: Technique demonstration with navigation tags
- **Video Background**: Seamless looping hero video
- **Image Reveals**: Dynamic RGB to IR transition effect

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Animations)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Inter, Playfair Display)
